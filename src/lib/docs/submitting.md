# Submitting Your Project

Submitting is short. Get your project onto GitHub, then fill out the submission form.

## Before you submit

Run through this list:

- [ ] The game launches and can be played start to finish.
- [ ] Your code is pushed to a **public** GitHub repository.
- [ ] A `README.md` explains what the game is and how to run it.
- [ ] Your hours are logged in Hackatime and Lapse.

## Publish your repository

If you've never used Git or GitHub, follow [GitHub's quickstart](https://docs.github.com/en/get-started/quickstart) first. Then:

```bash
git init
git add .
git commit -m "first playable build"
git branch -M main
git remote add origin https://github.com/<you>/<your-game>.git
git push -u origin main
```

> Commit **frequently**. A long history of small commits is a much better record of your work than one giant final commit.

## Send it in

1. Open the submission form (linked from the home page).
2. Paste your repository URL and a short description.
3. Confirm your Hackatime and Slack usernames so hours can be matched.

That's it — you're done. See [Prizes](/docs/prizes) for what your hours unlock.
