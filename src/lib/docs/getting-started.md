# Getting Started

**Storyboard** is a [Hack Club](https://hackclub.com) event for teenagers (13–18) who want to make a **visual novel**. You get a whole month to build one, and you earn prizes along the way.

> If you can write a story and click a few buttons, you can do this. No prior game-dev experience required.

## What you'll make

A visual novel is a story you play: backgrounds, character art, dialogue, and choices. You can build it with whatever tools you like, but most participants reach for [Ren'Py](https://www.renpy.org/), a free engine made exactly for this.

You'll finish the event with:

- a playable, finished story
- a GitHub repository holding your project
- logged hours that qualify you for prizes

## How it works

1. **Sign up** on the home page and join the `#storyboard` channel on the [Hack Club Slack](https://slack.hackclub.com).
2. **Make your story.** Write it, draw it, code it.
3. **Track your hours** as you go so they count toward prizes.
4. **Submit your project** before the deadline.

## The rules

| Rule        | Details                                                       |
| ----------- | ------------------------------------------------------------- |
| Age         | 13–18 at the time you participate                             |
| Team size   | Solo or small teams (split the hours fairly)                  |
| Content     | Keep it appropriate for a teen community                      |
| Originality | Your own writing and art, or assets you have the right to use |
